      How this works, and what it can't do
      

        

          The rewriting is not a re-implementation. This page runs the real
          normalize.py from the
          milisten CLI through Pyodide,
          so the two cannot drift apart. The voice is Kokoro-82M, the same model the CLI
          uses, running in this tab via ONNX — about 86 MB on first play, cached after.
        

        
Text you type and files you drop never leave your browser.
          Links are the exception: a browser cannot read another site directly, so a
          pasted URL is sent to r.jina.ai to extract the text. If you would
          rather nothing left the tab, download the page and drop the file instead.

        
    
          
  • No chaptered .m4b. That needs ffmpeg. The CLI
            builds real audiobooks with chapter marks; a browser tab cannot.
    • 
          
  • No queue. One document at a time. The CLI keeps a reading
            list across dozens of sources.
    • 
          
  • Bot walls still apply. Some publishers refuse automated
            readers outright; download those by hand.
    • 
        

        
For a real library: uv tool install milisten
